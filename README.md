\## 🌟 About The Project



\*\*JobConnect\*\* is a full-stack job portal application designed to connect job seekers with employment opportunities.



Users can explore job openings, search by job title and location, publish new vacancies, and submit job applications through a simple and responsive interface.



\## ✨ Key Features



\- 🔍 \*\*Smart Job Search\*\* – Search jobs by title and location.

\- 💼 \*\*Job Listings\*\* – Explore available job opportunities.

\- ➕ \*\*Post a Job\*\* – Add new job openings.

\- 📩 \*\*Apply for Jobs\*\* – Submit applications with applicant details.

\- 📋 \*\*My Applications\*\* – View submitted job applications.

\- 🗄️ \*\*Database Integration\*\* – Store jobs and applications using SQLite.

\- 📱 \*\*Responsive Design\*\* – User-friendly interface across devices.

\## ⚙️ Installation \& Setup



\*\*1. Clone the repository\*\*



```bash

git clone https://github.com/pavanbhusare19/job-portal-website.git

```



\*\*2. Navigate to the project folder\*\*



```bash

cd job-portal-website

```



\*\*3. Install dependencies\*\*



```bash

pip install -r requirements.txt

```



\*\*4. Start the application\*\*



```bash

python app.py

```



\*\*5. Open in your browser\*\*



```text

http://127.0.0.1:5000

```
